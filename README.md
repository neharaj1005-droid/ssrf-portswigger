# SSRF Labs - PortSwigger Web Security Academy

Write-ups from working through SSRF (Server-Side Request Forgery) labs on PortSwigger, as part of my MSc Cybersecurity coursework.

## Labs

1. [Basic SSRF Against the Local Server](./ssrf-lab1-basic-ssrf-local-server/README.md) - exploiting a stock check feature to reach the local admin panel and delete a user
2. [Basic SSRF Against Another Back-End System](./ssrf-lab2-another-backend-system/README.md) - same idea, but the admin panel was on an internal network and had to be found first using Burp Intruder to scan IPs

Each folder has its own README with the full walkthrough and screenshots.
